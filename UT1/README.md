# Introducción a los Ejercicios de Scripting en PowerShell
PowerShell es un entorno de línea de comandos y un lenguaje de scripting creado por Microsoft que permite automatizar tareas, administrar sistemas y trabajar con objetos de manera eficiente. Esta introducción ofrece una base para comenzar a realizar ejercicios prácticos en este lenguaje.

---

## ¿Qué es PowerShell?

PowerShell combina un shell interactivo con un lenguaje de scripting avanzado. Permite:

- Automatizar tareas repetitivas.
- Administrar sistemas Windows, Linux y macOS.
- Trabajar con objetos en lugar de texto plano.
- Utilizar cmdlets, módulos y funciones.

---

## ¿Qué es un script en PowerShell?

Un script es un archivo con extensión `.ps1` que contiene una secuencia de comandos que se ejecutan de forma automática. Facilitan la estandarización y automatización de tareas.
